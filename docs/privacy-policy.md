# Privacy Policy – Misstery Files Uploader

_Last updated: 2026-11-19_ · [Home](README.md) · [Terms of Service](terms-of-service.md)

**Misstery Files Uploader** is an internal tool operated by the owner of the YouTube channel
[Misstery Files (@missteryfiles)](https://www.youtube.com/@missteryfiles). It is used only by the
channel owner and is not offered to the public.

## What the tool does
- Uploads the channel owner's own videos to the owner's own YouTube channel and schedules their publish time.
- Sets custom thumbnails on those videos.
- Posts one comment (a discussion question) on the channel's own videos.
- Reads the channel's own YouTube Analytics reports to improve content.
- Publishes the same videos to the channel owner's own Instagram account.

## Data we access
The tool uses YouTube API Services, authorized only by the channel owner through Google OAuth.
It accesses only the channel owner's own channel, videos, comments it posts, and the channel's
aggregate analytics. It does not access, collect or store personal data of viewers or of any other
YouTube user.

## Storage and sharing
OAuth tokens are stored as private environment secrets available only to the channel owner.
Upload logs (video IDs, titles, publish times) are kept in the owner's private project files.
No data is sold, shared with third parties, or used for advertising.

## YouTube and Google
By using this tool, the channel owner agrees to the [YouTube Terms of Service](https://www.youtube.com/t/terms).
Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).
Access can be revoked at any time at [Google security settings](https://myaccount.google.com/permissions).

## Data deletion
Because the only user is the channel owner, revoking the app's access and deleting the private
project files removes all data held by the tool. Questions: contact the channel through its
YouTube "About" page.
