# Misstery Files Uploader

An internal publishing tool for the YouTube channel **[Misstery Files (@missteryfiles)](https://www.youtube.com/@missteryfiles)**.

<img src="youtube_icon.png" width="40" alt="YouTube"> **This tool uses YouTube API Services.**

## What it does
- Uploads the channel owner's own Shorts to the channel and schedules their publish time (YouTube Data API `videos.insert`)
- Sets the channel's own custom thumbnails (`thumbnails.set`)
- Posts one discussion question as a comment on the channel's own videos (`commentThreads.insert`)
- Reads the channel's own analytics (YouTube Analytics API)

It is used only by the channel owner, has no other users and is not offered to the public.
